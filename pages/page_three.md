## A useful open source software for European Studies

One incredibly useful tool for writing papers in the European Studies MA programme is *Zotero*. Zotero is an open source software which helps with collecting, organising, citing and sharing your sources. Given that it is a humanities study, sources and references quickly pile up and can become unmanageable easily. Zotero was originally created by the *Center for History and New Media* at *George Mason University* but since 2021, it is being developed by the *Corporation for Digital Scholarship* (Wikipedia).

Given that a Thesis in European Studies would include a variety of sources that would be more than tedious to manage on your own, Zotero is an incredibly useful tool so that the time spent on doing the management manually can instead be used on other more important aspects. 

The license Zotero runs on is GNU Affero General Public License, version 3 (AGPLv3) (GitHub). This license grants a lot of freedom on how to use the software but also gives obligations and restrictions on how the software is shared and distributed. The latest commit on main was on the 9th of November as of writing this, which is the also the 9th of November. There are 90 contributors to Zotero. While the majority of issues are closed on the GitHub page, there is still a quite significant number of open ones, which is 1412 (GitHub). Zotero is funded by a variety of people, though it currently appears to predominantly rely on user donations and subscriptions which grant more storage. 

Given what Zotero actually *does*, it seems like a reliable tool for a thesis but it is also possible to leave it since organising the sources manually is still an option.
